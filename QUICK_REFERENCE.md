## CRITICAL METRICS AT A GLANCE

### 🚨 Red Flags (Investigate Immediately)

1. **Stockouts**: >5% of products below reorder point
2. **On-Time Delivery**: <90% on-time rate
3. **Pending Orders**: >20% of orders not shipped
4. **Low Reviews**: <3.5 average rating
5. **Collection Rate**: <85% collection within 30 days
6. **Customer Churn**: >15% quarterly churn rate

**Response**: Escalate to department head immediately

---

### ✅ Green Indicators (Business Health)

1. **Customer Value**: Top 20% customers = 75%+ revenue
2. **Delivery**: 95%+ on-time rate
3. **Inventory**: 30-60 day supply maintained
4. **Reviews**: 4.0+ average rating maintained
5. **Cash Flow**: <30 day DSO achieved
6. **Loyalty**: 40%+ member penetration

**Action**: Maintain current strategy, optimize for efficiency

## HOW TO USE QUERIES FOR DECISIONS

### Example 1: Inventory Management Decision

**Situation**: Running low on stock, need to decide what to order

**Queries to Run**:
1. Basic Query 10: Show products below reorder point
2. Advanced Query 7: Check stock turnover rates
3. Basic Query 8: See recent sales trends

**Decision Questions**:
- Which products are critical (fast turnovers)?
- Which regions have the highest demand?
- What will be needed in next 30-60 days based on trends?

**Action**: Order urgent items today, plan 30-day purchases

---

### Example 2: Promotion Campaign Planning

**Situation**: Planning next month's promotional calendar

**Queries to Run**:
1. Advanced Query 3: Review seasonal trends
2. Advanced Query 10: Check previous promotion ROI
3. Advanced Query 2: Identify top-performing products

**Decision Questions**:
- What promotions performed best last year?
- What products should be promoted?
- What discount level drives sufficient volume?

**Action**: Replicate top promotions, test new mechanics for underperformers

---

### Example 3: VIP Customer Program Launch

**Situation**: Designing new VIP customer retention program

**Queries to Run**:
1. Advanced Query 1: Identify VIP customers
2. Advanced Query 12: Current loyalty program performance
3. Basic Query 3: Understand customer value distribution

**Decision Questions**:
- Who are our top 5% customers?
- How much do they spend vs. average?
- What will drive 2x spending increase?

**Action**: Design benefits that show 10-15x ROI, target VIP retention to 95%

## COMMON DECISION SCENARIOS

### Scenario A: "Our Sales Are Declining"
**Analyze**: 
- Advanced Query 3 (Seasonality - is it expected decline?)
- Advanced Query 2 (Product performance - which categories declining?)
- Basic Query 8 (Recent sales trend - how recent?)
- Advanced Query 1 (Customer acquisition - fewer new customers?)

**Solutions**:
- If seasonal: Launch promotional calendar
- If product-specific: Discontinue or improve products
- If new customer issue: Increase marketing budget
- If timing issue: Adjust operational efficiency

---

### Scenario B: "We Have Excess Inventory"
**Analyze**:
- Advanced Query 7 (Turnover analysis - which products slow?)
- Basic Query 10 (Stock levels - how excess?)
- Advanced Query 2 (Product performance - why not selling?)
- Advanced Query 3 (Seasonality - is it seasonal excess?)

**Solutions**:
- Fast movers: Increase marketing to volume
- Slow movers: Launch clearance promotion
- Dead stock: Liquidate at any price + discontinue
- Seasonal: Store for next season if feasible

---

### Scenario C: "Customer Satisfaction Is Declining"
**Analyze**:
- Advanced Query 8 (Review ratings - are products rated lower?)
- Advanced Query 4 (Delivery performance - faster delivery needed?)
- Basic Query 9 (Order fulfillment - are orders being delivered?)
- Advanced Query 12 (Loyalty satisfaction - member churn?)

**Solutions**:
- Low product ratings: Quality control + supplier pressure
- Late delivery: Logistics partner investigation + infrastructure
- Low fulfillment: Operations process improvement
- Member churn: Loyalty program redesign + benefits increase

---

### Scenario D: "Cash Flow Is Tight"
**Analyze**:
- Advanced Query 9 (Collection rate - are we collecting fast?)
- Advanced Query 7 (Inventory - cash tied up?)
- Advanced Query 5 (Payment methods - optimize processing?)
- Basic Query 3 (Customer value - focus on paying customers)

**Solutions**:
- Slow collections: Implement faster payment terms/methods
- Excess inventory: Liquidate slow-moving inventory
- High processing costs: Renegotiate with processors
- Wrong customer mix: Focus on credit-worthy customers
